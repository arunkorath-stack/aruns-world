Question banks

Sync all banks from the site

Re-loads every chapter of every subject from the bank files published with this site (banks/<SUBJECT>/seed_chNN.json) and replaces the chapter's questions in the Sheet. Use this after the banks have been corrected. Student attempts and answers are not touched.



Seed a bank (JSON)
Paste a bank file (the format Claude produces: subject, chapter, title, questions[]) and choose a status. Published questions are visible to students immediately; drafts are not.

Setup


1 · Connection
Script URL in use: 
Change it by editing config.json in the GitHub repo.


2 · Automatic question generation (GitHub Action)
Upload a chapter deck to uploads/<SUBJECT>/chNN_<title>.pptx in the repo (GitHub → Add file → Upload files). The Action extracts the slides, generates 30 draft questions with the Claude API using the course rules, and writes them to the Questions tab as draft. Review them under Question banks, fix wording, then set status to published.
Repo secrets required: ANTHROPIC_API_KEY, APPS_SCRIPT_URL, TEACHER_KEY.
